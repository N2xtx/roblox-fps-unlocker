## 📥 Installation

> ⚠️ **Prérequis** : avoir lancé **Roblox au moins une fois** (pour que les dossiers soient créés).

1. **Télécharge** la dernière version depuis [Releases](../../releases).
2. **Clic droit** sur l'exécutable → **Exécuter en tant qu'administrateur**.
3. Dans l'UAC Windows, clique sur **Oui**.
4. Dans le menu, choisis **[1] OPTIMISER**.
5. **Ferme et relance Roblox** → profite de tes FPS.

### 🔄 Restaurer

1. Relance l'outil.
2. Choisis **[2] RESTAURER**.
3. Redémarre Roblox.

---

## 🧠 Ce que l'outil modifie

| Fichier | Modification |
|---|---|
| `GlobalBasicSettings_13.xml` | `FramerateCap = 9999`, `GraphicsQualityLevel = 10` |
| `ClientSettings/FPSFlags.txt` | FFlags moteur |
| `GlobalBasicSettings_13.backup.xml` | Backup auto |

Tous les fichiers sont dans `%LOCALAPPDATA%\Roblox\`.
